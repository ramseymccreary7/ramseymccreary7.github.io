Key Forecasting Insight

Individual deal spreads are ~93% unexplainable with available data — property condition, ARV, negotiation, and buyer demand dominate but aren't captured here. However, at the office-month level, 61% of variance is explained by geography. The best lever for forecasting $/deal is projecting office mix shifts: if more volume flows through high-spread markets (CA, MA, GA) vs. low-spread markets (PA, KS, MO), blended $/deal moves materially.

Macro Backtest — 26 External Variables Tested

State-level housing data, national macro indicators, and interaction features tested against $/deal

Macro Backtest Result

After testing 26 external variables — including mortgage rates, 10-year Treasury yields, VIX, S&P 500, consumer confidence, existing home sales, state unemployment, state median home prices, HPI growth, housing inventory levels, and engineered interactions — none added statistically significant power beyond state geography (F-test p = 0.93). Median Home Price by state captures 85% of the geography effect, confirming $/deal is fundamentally driven by underlying property value levels in each market, not by macro cycle timing.
