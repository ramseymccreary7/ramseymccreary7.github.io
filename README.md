# Ramsey McCreary — FP&A Tools Portfolio

Working demos of dashboards, planning tools and finance automations I've built.
All company names, people, addresses and numbers are fictional; each demo runs in the browser
against generated data (the original Google Apps Script back-ends are replaced by `assets/gas-mock.js`).

- `index.html` — landing page
- `projects/` — live demos
- `case-studies/` — back-end / integration write-ups with code excerpts
- `assets/` — shared styles, demo runtime, vendored chart/map libraries
