NetSuite Auto Upload

Every night, new properties and loans from the CRM had to be created as customer records in NetSuite. This replaces the manual CSV import with a script that also checks its own work.

Google Apps ScriptNetSuite SuiteScript 2.1 RESTletToken-based authSuiteQL

How it flows

What I built

  • Apps Script builds the import file from the nightly pull and sends it to a NetSuite RESTlet over token-based auth.
  • The RESTlet saves the file to the File Cabinet and runs an allow-listed saved CSV import map.
  • Once the job finishes, it confirms with SuiteQL which rows actually landed (by External ID) and adds the secondary subsidiary that the CSV import can't set.
  • It watches the governance budget, returns "incomplete" when usage runs low, and resumes where it left off on the next call.

Outcome

  • A daily manual upload became an unattended job that reports exactly which rows are missing.

Code excerpt

  const post = (body) => {
    try {
      if (typeof body === 'string') body = JSON.parse(body);
      const fileName = String(body.fileName || '').trim();
      let contents = body.contents;
      const mappingId = String(body.mappingId || '').trim();

      if (!/\.csv$/i.test(fileName)) return fail_(`fileName must end in .csv (got "${fileName}")`);
      if (typeof contents !== 'string' || !contents.trim()) return fail_('contents is empty');
      if (contents.length > MAX_BYTES) return fail_('file is over ~9.5 MB; split it before sending');

      const allowed = allowedMaps_();
      if (!allowed.length) return fail_('custscript_csv_allowed_maps is not set on the deployment');
      if (allowed.indexOf(mappingId.toLowerCase()) === -1) return fail_(`mappingId "${mappingId}" is not allow-listed`);
      if (!folderId_()) return fail_('custscript_csv_folder is not set on the deployment');

      contents = contents.replace(/^﻿/, '');

      const fileId = file.create({
        name: `${stamp_()}_${fileName}`.slice(0, 199),
        fileType: file.Type.CSV,
        contents,
        folder: folderId_(),
        encoding: file.Encoding.UTF_8
      }).save();

      const imp = task.create({ taskType: task.TaskType.CSV_IMPORT });
      imp.mappingId = mappingId;
      imp.importFile = file.load({ id: fileId });
      imp.name = `Auto Import - ${fileName}`.slice(0, 100);
      if (body.queueId) imp.queueId = Number(body.queueId);
      const taskId = imp.submit();

      log.audit('CSV Import submitted', { fileName, fileId, mappingId, taskId });
      return { ok: true, taskId, fileId };
    } catch (e) {
      return fail_(`${e.name || 'Error'}: ${e.message || e}`);
    }
  };
