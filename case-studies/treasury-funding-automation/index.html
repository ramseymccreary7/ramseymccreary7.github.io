Treasury & Lender Funding Automation

For a bridge-lending business, each new loan has to be funded from internal cash or one of several outside lenders, each with its own limits. This workflow recommends the funder, tracks the money and builds the accounting entries.

How it flows

What I built

  • Uses internal operating cash first while keeping a stage-weighted buffer for upcoming closings, then picks outside lenders by priority, room under their cap, minimum balance and state eligibility.
  • Approving moves the loan into that lender's section of the treasury ledger and updates the live funding mix.
  • Pulls bank balances and incoming wires. A loan flagged "funding pending" clears automatically when the lender's wire lands with the property address in the memo.
  • Pulls the loan servicer's disbursement report through its GraphQL API and builds the daily NetSuite journal entry with a button.

Outcome

  • Funding decisions follow written rules, and the rules are visible on every recommendation.
  • Replaced a formula-heavy treasury workbook with script-driven refreshes that others can run.

Code excerpt

function tfPlan_(pending, lenders, freeStart) {
  let free = freeStart;
  const bal = {};
  lenders.forEach(l => { bal[l.name] = l.balance; });
  const opf = lenders.find(l => l.isOpf);
  const outside = lenders.filter(l => !l.isOpf);
  const byName = {};
  lenders.forEach(l => { byName[l.name.toLowerCase()] = l; });
  const room = l => (l.max === null || l.max === '' || isNaN(l.max)) ? Infinity : l.max - bal[l.name];
  const fits = (l, p) => room(l) >= (l.isOpf ? p.net : p.amount) &&
                         (!l.maxSingle || p.amount <= l.maxSingle) &&
                         !(l.excluded || []).includes(String(p.state || '').toUpperCase());

  const order = pending.slice().sort((a, b) => (tfTime_(a.fundDate) - tfTime_(b.fundDate)) || (a.row - b.row));
  const recs = [];
  order.forEach(p => {
    let pick = null, why = '', warn = false;
    const ov = p.override ? byName[String(p.override).toLowerCase()] : null;
    if (ov) {
      pick = ov; why = 'Override';
      if (!fits(ov, p)) { warn = true; why += ` ⚠ ${ov.name} lacks room/eligibility (room ${tfMoney_(room(ov))})`; }
    } else if (opf && free >= 0 && fits(opf, p)) {
      pick = opf;
      why = `Op Fund keeps it — free cash ${tfMoney_(free)} after pipeline buffer + min cash` +
            (room(opf) === Infinity ? '' : `; Op Fund room ${tfMoney_(room(opf))}`);
    } else {
      const reason = (opf && free < 0) ? `Op Fund short ${tfMoney_(-free)} vs buffer + min cash`
                                        : `Op Fund at its cap (room ${tfMoney_(opf ? room(opf) : 0)})`;
      const elig = outside.filter(l => fits(l, p)).sort((a, b) => {
        const au = bal[a.name] < (a.min || 0) ? 0 : 1, bu = bal[b.name] < (b.min || 0) ? 0 : 1;
        return (au - bu) || ((a.priority || 99) - (b.priority || 99)) || (room(b) - room(a));
      });
      if (!elig.length) {
        pick = opf; warn = true;
        why = reason + ' — ⚠ no outside lender has room / eligibility; review';
      } else {
        pick = elig[0];
        why = reason + '; ' + (bal[pick.name] < (pick.min || 0)
          ? `${pick.name} is under its ${tfMoney_(pick.min)} minimum`
          : `${pick.name} is priority ${pick.priority || '—'} with ${tfMoney_(room(pick))} room`);
      }
    }
    if (pick.isOpf) bal[pick.name] += p.net;
    else { bal[pick.name] += p.amount; free += p.amount; }   // lender wires back the full loan amount
    recs.push({ row: p.row, loanNo: p.loanNo, lender: pick.name, why, warn, amount: p.amount, net: p.net });
  });
  return { recs, balAfter: bal, freeAfter: free };
}

The recommendation pass: internal cash first, then outside lenders by eligibility, minimum balance, priority and room. Identifiers and internal names are anonymized.
