Tee Time Booking Bot

Popular tee times at my club fill within seconds of the booking window opening. This bot signs in early, waits with millisecond precision, and books the best time that matches my preferences.

PythonPlaywrightasyncioWindows Task Scheduler

How it flows

What I built

  • Playwright drives the club's member portal and reuses the saved session so login doesn't cost time at the open.
  • Waits coarsely with asyncio, then busy-waits the last 300 ms so it fires right on the opening second.
  • Parses the available times, ranks them against preferred windows and player count, and books the first acceptable one. A dry-run mode makes testing safe.
  • A PowerShell script registers it as a scheduled task that starts a few minutes before the window opens.

Outcome

  • Turned a race against the clock into a scheduled task.

Code excerpt

async def precise_sleep_until(target_dt: datetime.datetime):
    """
    Sleep until target_dt with ~1 ms precision.
    Uses asyncio.sleep for the bulk of the wait, then busy-waits
    the final 300 ms so we don&#x27;t overshoot due to scheduler jitter.
    """
    target_ts = target_dt.timestamp()
    # Coarse async sleep (gives up the event loop, low CPU)
    coarse = target_ts - time.time() - 0.3
    if coarse > 0:
        await asyncio.sleep(coarse)
    # Busy-wait for the last 300 ms
    while time.time() < target_ts:
        pass
