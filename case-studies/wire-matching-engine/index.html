Bank API → CRM matching

Wire Matching Engine

Accounting specialists used to match every incoming down payment, admin fee and earnest-money wire to its deal by hand. The bank and the CRM share no ID, so this engine matches them with fuzzy logic and leaves the decision with a person.

Google Apps ScriptAWS Lambda proxyBank treasury API (OAuth)Salesforce SOQLNetSuite

How it flows

What I built

  • Pulls wires on demand from the bank's treasury API through an AWS Lambda proxy, so credentials never sit in the spreadsheet.
  • Reads deals awaiting money from Salesforce with the same criteria as the existing "pending down payment" alert.
  • Scores each wire–deal pair on house number, street-name similarity (directionals handled), ZIP, and a date window around closing. Each match gets a grade: Exact, High, Medium, Low or Review.
  • Approve checkboxes generate the NetSuite invoice upload and the CRM field updates in one step. A permanent wire history keeps a wire from being posted twice.
  • Wires that don't match can be paired by hand from a dropdown, and the same workbook copies cleanly to other markets.

Outcome

  • Turned a manual, line-by-line reconciliation into review and approve.
  • Built so other accounting specialists run it themselves, each scoped to their own offices and legal entities.

Code excerpt

function scorePair_(wire, deal) {
  var addr = scoreAddress_(wire, deal);
  if (!addr.numHit || addr.street < CFG.STREET_MED) return null;

  var score = 0.70 * addr.street + (addr.zipHit ? 0.20 : 0) + 0.10;

  var anchor = wire.direction === 'OUT' ? deal.created : deal.dispClose;
  var dd = daysBetween_(wire.date, anchor);
  if (dd !== null) {
    var before = wire.direction === 'OUT' ? CFG.EMD_DAYS_BEFORE : CFG.DP_DAYS_BEFORE;
    var after  = wire.direction === 'OUT' ? CFG.EMD_DAYS_AFTER  : CFG.DP_DAYS_AFTER;
    if (!(dd >= -before && dd <= after)) score -= 0.10;
  }

  return { wire: wire, deal: deal, addr: addr,
           score: Math.max(0, Math.min(1, score)), dayDelta: dd };
}

function bandFor_(c, margin) {
  if (margin < CFG.MARGIN_MIN) return 'Review';
  if (c.addr.street >= CFG.STREET_EXACT && (c.addr.zipHit || !c.deal.addr.zip)) return 'Exact';
  if (c.addr.street >= CFG.STREET_HIGH) return 'High';
  if (c.addr.street >= CFG.STREET_MED) return 'Medium';
  return 'Low';
}
